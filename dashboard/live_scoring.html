Score a new dataset

Upload a CSV with the same raw column schema as the competition dataset (the 3,924 F-columns; F3924 ground-truth is optional — include it to see accuracy metrics, omit it to score an unlabeled file). This runs the full bundled ensemble — all 5 supervised models, the meta-learner, the Stage-2 cascade, the whole-population triage clusters, and per-account SHAP — via production/serving/score_new_dataset.py, not the single-model shortcut.

Scoring in progress — this runs all 5 models + meta-learner + cascade + clustering (and SHAP, if checked) over every row. Larger files take longer; do not close this tab.

What happens to your upload

  • Every upload gets its own id (e.g. upload_20260823_1430) and its own stored result — a new upload never overwrites a previous one.
  • Once scored, the dataset becomes selectable in the Investigator Console's dataset dropdown, and each account's row links to a real 3D risk-fingerprint view.
  • If the uploaded file's columns don't match the trained schema, scoring is refused with the exact column diff rather than silently producing a misleading result.
  • If the file has no F3924 label column, accuracy metrics (AUC-PR etc.) are not shown — they cannot be honestly computed without ground truth, and are never fabricated.
