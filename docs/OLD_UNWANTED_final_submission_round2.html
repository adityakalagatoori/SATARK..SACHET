Detection Models

Model A — NNPU PU Learner Core Innovation

Non-Negative PU loss (Kiryo et al., NeurIPS 2017) via a custom LightGBM gradient/Hessian objective — corrects 99:1 imbalance at the training objective level. No SMOTE.
Design: per-sample (not batch-averaged) gradients, with a non-negative floor on the estimated risk correction (Kiryo Thm. 1)  ·  π=0.01
OOF AUC-PR: 0.75  ·  Learned meta-weight: largest of all 5 models

Model B — Cost-Sensitive LightGBM Supervised Anchor

scale_pos_weight = 9001/81 ≈ 111. No SMOTE — synthetic patterns damage explainability (ArXiv 2025). Primary metric: AUC-PR, not AUC-ROC.
Nested CV: mutual-info selects top-150 features per fold on training partition only. Test fold never consulted during selection.
OOF AUC-PR: 0.800  ·  strongest single model  ·  150 features selected per fold

Model E — CatBoost Ordered Boosting

Second independent gradient-boosted learner. Ordered boosting computes each tree's gradients from a permutation of prior rows only, reducing target-leakage risk on a small (81-row) positive set.
Nested CV: same leak-free per-fold feature selection as Model B, independently re-fit.
OOF AUC-PR: 0.75  ·  positive learned meta-weight alongside LightGBM

Model C — ECOD + Deep Isolation Forest Zero-Day

Fully unsupervised — zero labels. Scores all 9,082 accounts against the full distribution, catching typologies absent from the 81 labeled mules.
ECOD (Li et al., IEEE TKDE 2022): CDF-based, hyperparameter-free.  Deep-IF (Chen et al., IEEE TKDE 2023): neural encoder + isolation forest. Complementary failure modes.
Diagnostic-only labeled AUC-PR is low by design — not calibrated to the 81-mule subset; role is zero-day coverage in the ensemble

Data Integrity — Features Excluded From Training

F2230 MNTH — separates accounts by data-collection batch month, not by account behavior, and is unavailable at inference time. Excluded from all training and reported metrics.
F3912 FRAUD_SUSPECTED — documented in the official feature dictionary as a resolution-status flag, i.e. a post-investigation label. Using it as a predictor would mean training on the answer itself. Excluded.
Unnamed:0 Row index — direct lookup invalidates CV. Commonly missed in default DataFrame loading; explicitly excluded here.

Bank-Finalized Features — Tested, Not Forced

The official data dictionary marks 18 features as Bank_Finalized_Variables (age, tenure, balance, occupation, etc.). We tested forcing all 18 into the selected feature set: OOF AUC-PR dropped from 0.80 to 0.73. This indicates they function better as investigator-facing context than as raw predictive signal for the classifier, so they are surfaced in the alert payload rather than forced into the model.

Non-Standard Technical Choices — Why Each Decision Was Made

ProblemSACHET's Choice & Rationale
No transaction graph — only account-level aggregates GNN requires per-transfer edge data (sender→receiver). Dataset provides 3,924 account-level features; no individual transaction records exist. K-Means on the engineered feature space is the clustering approach consistent with the available data structure.
99:1 class imbalance NNPU loss (Kiryo et al., NeurIPS 2017) — corrects at training objective, via a custom LightGBM gradient/Hessian objective. No SMOTE; no synthetic patterns that damage explainability (ArXiv 2025).
Single-model risk on 81 positives Two independent GBMs — LightGBM and CatBoost, separately fit and feature-selected, reduce reliance on any one model's idiosyncrasies at this sample size.
Feature selection leakage Nested per-fold selection — mutual-info top-150 features chosen inside each fold's training partition only. Test fold never consulted during selection.
New mule typologies (zero-day) ECOD + Deep-IF (dual unsupervised) — complementary anomaly failure modes. ECOD: CDF-based marginal outliers. Deep-IF: neural isolation for non-linear anomalies. Together cover patterns absent from 81 training labels.
Ensemble weighting Stacked LR meta-learner on OOF predictions — weights emerge from data, not hand-tuned; NNPU and LightGBM carry the largest positive weights.
SHAP explainability (circular use) SHAP post-training only — never used for feature selection. Avoids circular importance inflation. Bank feature dictionary maps F-codes to business names in deployment.
Real-time PS-2 feeds Flask REST API — CBS hook calls the scoring endpoint inline. NCRP + RBI flags append as binary features pre-call. No model retraining required.

Technical Innovations, Roadmap & References Page 5 of 6

Four Technical Innovations

1 NNPU Loss — Imbalance Correction at Training Objective
Non-Negative PU loss (Kiryo et al., NeurIPS 2017), implemented as a custom LightGBM gradient/Hessian objective. Treats 9,001 unlabeled accounts correctly — no SMOTE, no synthetic patterns. Only model class that doesn't assume the unlabeled set is confirmed clean.
OOF AUC-PR 0.75  ·  largest learned meta-weight among all 5 models
2 Leakage-Free True Nested CV
Feature selection (mutual-info, top-150) runs exclusively inside each fold's training partition — test fold never consulted. Prevents optimistic estimates at 81 positives. Global pre-CV selection was tested and found to inflate AUC-PR to 1.0000 after a single boosting round — itself diagnostic of leakage.
150 features selected per fold  ·  every reported metric is out-of-fold
3 Two Independent Gradient-Boosted Learners
LightGBM and CatBoost are trained and feature-selected independently, each contributing a distinct OOF signal to the meta-learner. CatBoost's ordered boosting reduces target-leakage risk specific to a small (81-row) positive set.
Both carry positive learned meta-weights; ensemble beats either model alone
4 Dataset Integrity + Unsupervised Behavioral Clustering
F2230 (batch-month artifact, unavailable at inference) and F3912 (documented post-investigation resolution flag) excluded. K-Means (k=5, unsupervised) finds 87.7% of confirmed mules co-locate in one cluster — 3.4× investigator efficiency.
Cluster 0: 2,342 accounts · 71 mules · 3.03% rate vs 0.89% population

Why Tabular ML — Not Graph Neural Networks

The dataset provides 3,924 account-level aggregate features — no individual transaction records and no cross-account payment edges. GNNs require actual money-transfer edges between named accounts. A graph built from feature similarity (cosine, correlation) represents statistical proximity between account feature vectors — not actual transactions. These are different quantities. K-Means on the engineered feature space captures account groupings consistent with the available data structure; GNN approaches apply where transaction-level edge data exists.

Key Engineering Findings

All produced by python src/satark.py --mode full-ensemble on the competition dataset
1. F2230 — Batch-Month Artifact
Documented as a data-collection month indicator, not a behavioral signal, and unavailable at inference time. Excluded — SACHET metrics are computed without it.
2. F3912 — Post-Investigation Flag
Documented in the official feature dictionary as FRAUD_SUSPECTED, a resolution-status flag. Using it as a predictor trains on the answer. Excluded.
3. Naive Feature Selection Collapses to 1.0000
Selecting features on the full dataset before splitting produced a spurious 1.0000 AUC-PR after one boosting round — a leakage signature, not model quality. Fixed via strict per-fold selection.
4. Unsupervised Mule Concentration
K-Means (k=5, no labels) places 71/81 mules in one cluster (87.7%). Unsupervised — labels never seen during clustering, only used afterward to measure density.
5. Bank-Finalized Features Tested, Not Forced
Forcing the 18 officially bank-marked features into the model dropped AUC-PR from 0.80 to 0.73 — they carry more value as investigator context than as raw model signal.
SACHET — Core Technical Differentiators
→Positive-Unlabeled Learning (NNPU, NeurIPS 2017) — treats 9,001 uninvestigated accounts as unlabeled, not confirmed negative. Custom LightGBM gradient/Hessian objective with a non-negative risk floor.
→Five independently-validated models — LightGBM, CatBoost, NNPU, ECOD, Deep Isolation Forest, combined via a logistic-regression meta-learner whose weights are learned, not hand-tuned.
→True nested cross-validation at 81 positives — feature selection confined strictly to each fold's training partition. Every reported metric is out-of-fold.
→Dataset integrity verified, not assumed — F2230 and F3912 identified as artifacts and excluded; the 18 bank-finalized features were tested empirically rather than assumed useful.
→Behavioral triage validated against ground truth — unsupervised K-Means, fit with zero labels, concentrates 87.7% of confirmed mules in one cluster spanning 26% of accounts.
